# Release checklist

- [ ] Conversion manifest reviewed; no unexplained source behavior omitted.
- [ ] All feature statuses accurately marked ported/adapted/deferred/rejected.
- [ ] SLeeLa 2.9 compilation succeeds with recorded compiler version.
- [ ] All pure domain tests pass.
- [ ] Filesystem bridge is implemented and reports its capabilities.
- [ ] Dry-run is proven non-mutating.
- [ ] Copy, digest verification, and no-overwrite behavior pass.
- [ ] Recovery tests pass at every transaction boundary.
- [ ] Linux, Windows 10+, and macOS test evidence is attached.
- [ ] Security and privacy review completed.
- [ ] Format registry matches tested adapters, not extension recognition.
- [ ] README and release notes distinguish verified functionality from planned work.
- [ ] No secrets, private media, or personal metadata are committed.
- [ ] Release tag identifies the exact verified commit.
